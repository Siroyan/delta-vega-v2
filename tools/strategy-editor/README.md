# 走行戦略エディタ

Tab5のコースデータを地図に表示し、周回ごとのエンジンON/OFF案内地点を編集するローカルWebアプリです。戦略はドライバーへの案内用で、車両のGPIOを自動操作しません。

## 起動

リポジトリのルートで実行します。Python 3.9以上が必要です。追加パッケージは不要です。

```sh
cd tools/strategy-editor
python3 -m strategy_editor.web
```

ブラウザで <http://127.0.0.1:8766/> を開きます。既定ではこのPCからだけ接続できます。ポートを変える場合は `--port 8767` のように指定してください。

## 使い方

1. コースを選ぶか、同梱の戦略または手元のJSONを読み込みます。編集途中の内容は同じブラウザのローカルストレージに自動保存され、再読込で復元されます。
2. `PLAN ID` と `PLAN TYPE` を設定します。各LAPを開き、ON/OFF地点を経路始点からの距離（m）で入力するか、地図の丸印をドラッグします。数値欄を選択してから地図をタップしても地点を設定できます。
3. 必要なら区間を追加し、他の周回へコピーします。コピー時に経路長を超える周回はスキップされます。最終周のゴール分岐など、コピー後に各周を確認してください。
4. 検証結果が「Tab5の戦略形式に適合しています。」となったらJSONを書き出します。microSDの `/vega/strategies/` にコピーし、Tab5のWaiting画面にある `COURSE / STRATEGY` から選択します。

新規戦略のON/OFF距離は両方とも0 mから始まります。すべての周回を有効な区間に編集するまで書き出せません。エディタは全周の定義、距離順、区間数、経路ID、識別子、ファイル名、4096バイト上限を確認します。読み込んだJSONにも同じ検証を行います。

茂木100周コースはコースとして選べますが、現行Tab5の戦略パーサーは最大7周のため戦略JSONを書き出せません。この制約は画面に表示されます。

コースの編集元は [`assets/maps/`](../../assets/maps/README.md)、戦略JSONの仕様は [`assets/strategy/`](../../assets/strategy/README.md) を参照してください。

## テスト

```sh
python3 -m unittest discover -s tools/strategy-editor/tests -v
```

同梱戦略の往復、入力検証、HTTP API、エディタ出力をファームウェアのC++パーサーで読む互換テストを実行します。C++コンパイラがない環境では最後の互換テストをスキップします。
