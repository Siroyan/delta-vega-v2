# 走行戦略データ（schema 1）

`motegi_demo.json`は**表示と読込を確認するためだけのダミー**です。1周目はスタート地点の0 mでON、全7周に各3回のON/OFF区間を仮置きしています。実際の車両・コースでの点火地点や電装OFF地点を示すものではありません。車両出力の自動制御には使用せず、ドライバー向けの案内と地図描画にのみ使用します。

## Tab5に読み込ませる

microSDのルートに`vega`フォルダを作り、採用するJSONを`/vega/strategy.json`としてコピーしてからTab5を起動します。ファームウェアはSDのマウント後に一度読み込みます。戦略を差し替えたときはTab5を再起動してください。ファイルがない場合は`PLAN NOT SET`、形式またはコースが合わない場合は`PLAN INVALID`を表示します。セッションログの`/vega/session-*.jsonl`とは別のファイルです。

初回の表示確認では、同梱の[`motegi_demo.json`](motegi_demo.json)を`strategy.json`という名前でカードへコピーしてください。Waiting画面では1周目をプレビューし、計測中は現在周回に切り替わります。現在位置に基づく残り距離の案内はGPS受信後に表示されます。GPSがない場合も、周回に対応する橙色のエンジン使用区間、青色の惰性区間、点火とOFFの地点を地図へ表示します。

以前の`dummy-race-001`を保存したカードは自動更新されません。新しいデモの`plan_id`は`dummy-race-002`です。表示を切り替える場合はカード上の`/vega/strategy.json`を置き換えて再起動してください。

Tab5にカードを挿したまま初回データを転送する場合は、USBシリアル接続で次のコマンドも使えます。`pyserial`が必要です。既存の`strategy.json`がある場合、転送は**上書きせず拒否**します。既存プランの更新はカードをPCで編集し、Tab5を再起動してください。
この初回転送は保存後すぐに画面へ反映されます。

```sh
python3 scripts/upload_strategy.py assets/strategy/motegi_demo.json --port /dev/cu.usbmodem1101
```

## フォーマット

```json
{
  "schema_version": 1,
  "course_id": "motegi_oval_2025_full_v2",
  "plan_id": "example-001",
  "plan_type": "demo",
  "laps": [
    {
      "lap": 1,
      "route_id": "first_lap",
      "runs": [{"on_s_m": 0, "off_s_m": 300}]
    }
  ]
}
```

実ファイルには**1〜7周の全周**を重複なく入れます。上の抜粋は構造の説明です。

| 項目 | 意味 |
|---|---|
| `schema_version` | 現在は`1`のみ |
| `course_id` | ファームウェアに組み込んだコースのIDと完全一致させる |
| `plan_id` | 戦略の識別子。英数字、`_`、`-`、`.`のみ、39文字以内 |
| `plan_type` | `demo`なら画面に`PLAN DEMO`と表示。実戦略は`race` |
| `lap` | 1〜7。順序は自由だが全周必須 |
| `route_id` | 1周目は`first_lap`、2〜6周目は`regular_lap`、7周目は`final_lap` |
| `runs` | その周の点火から電装OFFまでの区間。1〜3件、距離順 |
| `on_s_m` | 経路の始点から測った、エンジン始動を促す地点（m） |
| `off_s_m` | 同じ経路上で電装OFF・惰性走行開始を促す地点（m） |

橙色は各`on_s_m`から`off_s_m`まで、青色はそれ以外の区間です。複数の`runs`があれば、前のOFFから次のONまでを青色にします。指示地点は計画値であり、Tab5はエンジンの実稼働状態を検知できません。`on_s_m`では電装ONとECU準備後のIGNITIONが必要になる場合がありますが、その操作判断はドライバーが行います。

距離`s_m`は緯度経度でもレース全体の通算距離でもなく、**各`route_id`の始点からの距離**です。[コースJSON](../motegi_oval_full/motegi_course_full.json)の`routes.*.points[].s_m`と同じ定義です。1周目は約2124.58 m、通常周は約2412.01 m、最終周は約2208.10 mです。旧コースの`s_m`をそのまま流用しないでください。

ファイルはUTF-8のJSON、4096バイト以内です。キー名と識別子はASCII英数字、`_`、`-`、`.`を使用し、数値は0以上の通常の10進表記にします。各周で`0 <= on_s_m < off_s_m <= 経路長`、次の`on_s_m > 前のoff_s_m`を満たしてください。未知の項目、重複した項目、コースID不一致、範囲外の距離はファイル全体を不採用にします。運用時は`plan_id`を変更して版を識別してください。

開発時に最初に配布した`dummy-race-001`だけは、旧形式の`plan_type`省略を`demo`として読み込めます。新規ファイルには必ず`plan_type`を指定してください。
