# 飛田給・榊原記念病院周回テストコース

指定された `35.666947, 139.518721` を起点に、榊原記念病院の周囲を公道で回る約1.02 kmの暫定コース。道路は OpenStreetMap のデータを基にした。画像にはコース線だけを描き、病院の網掛けは表示しない。測量や現地 GPS 軌跡による校正前のため、道路の通行可否・進行方向・歩道や自転車の走行位置は現地で確認する。

## 経路と判定地点

STARTから北側道路を東進し、病院東側を南下する。国道20号（甲州街道）を西へ進み、朝日町通りを北上してSTARTへ戻る。国道20号のOSM上の西向き一方通行に沿う方向で経路を作成した。前版は国道20号を避けて南側へ大きく迂回していたため、今回の経路に修正した。

| 地点 | 緯度 | 経度 | 用途 |
|---|---:|---:|---|
| START | 35.666947 | 139.518721 | 指定座標。ドライバーの操作で計測を始める位置の目安 |
| LAP | 35.6665666 | 139.5186953 | STARTの約39 m手前。1〜3回目の自動周回更新 |
| GOAL | 35.6669552 | 139.5219829 | 4周目、LAPから約338 m進んだ病院北東側の自動完走判定 |

1周目は約983 m、2〜3周目は各約1,022 m、最終周はLAPからGOALまで約338 m。4周完走までの経路長は約3.37 km。LAPからGOALまでの距離は、ファームウェアのゴール判定に必要な最低前進距離100 mより長い。病院のOSM外形の外周だけで約644 mあるため、敷地全体を囲む経路を500 m以下にはできない。ユーザー指定により、今回は病院全体を囲むことを優先した。

## ファイルと切替

- `course.json`：WGS84座標、累積距離、画素変換、4周の経路、判定地点。
- `tobitakyu_course.svg`：480 pxの原画。
- `tobitakyu_course_480.png`：実機の背景画像。地点マーカーはファームウェア側で重ねる。
- `tobitakyu_course_preview.png`：地点を重ねた確認用画像。

このコースは他の収録コースとともにファームウェアへ組み込み、Waiting画面で選択する。飛田給のSettingsは専用のNVS領域`vega-tobi4`に保存される。以前の`vega-tobi2`設定があれば読み込み、全体目標が旧初期値の140分なら80分へ更新する。新規の初期値はSTART・LAP・GOAL、コース回廊30 m、各周20分・全体80分。走行戦略は選択したコースIDと4周の経路に適合するものだけを採用する。

4周目のGOALは病院北東側の通常経路上にあり、専用のゴール分岐はない。4周目にはMANUAL LAPボタンも手動GOALへ変わる。Settingsでは未使用のLAP 5〜7を隠す。屋外GPSでの走行軌跡・周回更新・ゴール判定は現地試験で確認する。経路上の交差点では交通ルールを優先し、端末の操作と画面確認は停止して行う。

## 出典

道路と病院の形状は[OpenStreetMap contributors](https://www.openstreetmap.org/copyright)のデータ（ODbL 1.0）。取得範囲と道路way IDはJSONの`source`に記録した。病院の所在地は[榊原記念病院の概要](https://www.hp.heart.or.jp/about/overview.html)とも照合した。

## 実機の初期確認

2026-10-01に国道20号を使う本版をTab5へ書き込み、Waiting画面のコースとSTART・LAP・GOAL、地図下端の横並び凡例を目視確認した。凡例とGOAL点・コース線の重なりは解消済み。ビルドとローカルテストは通過し、書き込みハッシュも一致した。シリアルでは初期座標、GPS入力先PORT.A、SD正常、電装OFFを確認した。屋外GPSでの位置追従、実走での周回・ゴール判定は未検証。
